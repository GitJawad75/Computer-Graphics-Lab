# Signal Master – Smart Traffic Control

## Project Overview
Signal Master is a 2D traffic signal simulation developed using C++ and OpenGL. It simulates a four-way road intersection where vehicles move according to traffic light signals.

## Technologies Used
- C++
- OpenGL 3.3
- GLFW
- GLAD
- GLSL Shaders

## Features
- Four-way road intersection
- Four moving cars
- Horizontal and vertical traffic signals
- Manual traffic light control
- Vehicles stop at red signals
- Real-time 2D graphics simulation

## Keyboard Controls
- `1` – Activate horizontal green signal
- `2` – Activate vertical green signal
- `ESC` – Exit the program

## Working Principle
The system controls vehicle movement using horizontal and vertical traffic signals. When one direction has a green signal, its cars move, while the other direction's cars stop before the stop lines. The user can switch signals using the keyboard.

## Conclusion
Signal Master demonstrates the basic concept of traffic signal management through an interactive 2D graphics simulation using C++ and OpenGL.
