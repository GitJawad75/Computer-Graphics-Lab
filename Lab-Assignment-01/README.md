## Objective

The objective of this assignment is to create a magenta-colored window using OpenGL/GLUT. The window title displays my full name, and pressing the first letter of my name (**J**) closes the window.

---

## Program Features

- Creates a magenta-colored window.
- Displays **"Jawad Ul Karim"** as the window title.
- Closes the window when the **J** key is pressed.
- Written in C++ using the OpenGL/GLUT library.
- Includes comments for better readability and understanding.

---

## Technologies Used

- C++
- OpenGL
- GLUT (FreeGLUT)
- Visual Studio Code

---

## How to Compile

Use the following command to compile the program:

```bash
g++ main.cpp -o app -lglut -lGL -lGLU
````

---

## How to Run

After successful compilation, run the program using:

```bash
./app
```

---

## Expected Output

* A magenta-colored window appears.
* The window title is **Jawad Ul Karim**.
* Pressing the **J** key closes the window.
