OpenGL Animated Triangle

Description:
A simple OpenGL project that displays an upside-down triangle at the center of a black background.

Features:
Triangle color smoothly changes between cyan and white.
Pressing Escape changes the triangle color to red.
Window title is set to the student ID.
Uses OpenGL, GLFW, GLAD, and GLSL.
Controls
Escape: Close the window.
